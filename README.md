
# Gatekeeper Shift

A tactical grid racing game for two local players.

## Features

- 2 Player Local Multiplayer
- 9x9 Grid Board
- Rotatable Directional Gates
- Strategic Obstacles
- Turn-Based Gameplay
- Keyboard Controls
- Victory System
- Responsive Design

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## How to Play

1. Move one tile per turn.
2. Rotate one gate per turn.
3. Follow the direction of gate arrows.
4. Reach the finish line before your opponent.

## Run Locally

Open index.html in your browser.

## GitHub Pages

1. Upload all files to your repository.
2. Open Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select main and /(root).
6. Click Save.
